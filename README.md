# Base visual — ECG ROI Segmentation Dataset

**Fonte selecionada pelo grupo:** https://www.kaggle.com/datasets/gowrishankarp/ecg-dataset-cropped

**Nome exibido na fonte:** ECG ROI Segmentation Dataset.

A atividade exige no mínimo 100 imagens `.jpg` ou `.png` de um exame cardiológico. O conjunto completo permanece referenciado na fonte pública do Kaggle para evitar duplicação desnecessária de arquivos pesados no GitHub.

## Aplicação prevista em Visão Computacional

As imagens de ECG podem ser utilizadas para pré-processamento, definição/segmentação de regiões de interesse (ROI), detecção de linhas e contornos, extração de características visuais e, caso os rótulos disponíveis sejam adequados, treinamento de modelos de classificação ou reconhecimento de padrões.

## Governança antes da submissão

1. Confirmar na página do Kaggle que o recorte escolhido contém **pelo menos 100 imagens `.jpg` ou `.png`**.
2. Registrar a **licença/termos de uso** informados no Data Card do Kaggle.
3. Verificar se as imagens apresentam nomes, IDs, datas ou outros identificadores de pacientes; se houver, não redistribuir sem anonimização apropriada.
4. Documentar classes/rótulos e distribuição por classe antes de utilizar a base em treinamento de modelos.

> Não inferimos no README se as imagens são reais ou sintéticas, pois essa informação não pôde ser confirmada de forma confiável na página pública acessível durante a preparação. O grupo deve registrar essa informação após conferir o Data Card do Kaggle.
